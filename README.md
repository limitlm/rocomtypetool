
# 洛克王国属性克制查询工具（自用）

## 项目概述

市面上已经有很多属性克制查询小工具，本项目主要是为了方便个人使用而开发的。
我喜欢研究配队，想知道哪些属性组合成的配队，打击面和联防面能够同时覆盖较多的属性。
不过微信小程序上的配队都需要选择宠物，选择技能后才能查看，而且不能查看打击盲点和联防盲点，非常不方便，所以我索性自己写一个，可以免费部署到EdgeOnePages上。

### 核心功能

- **单属性查询**：查询单一属性的完整克制关系
- **双属性查询**：支持两种属性组合的克制关系查询，采用标准游戏算法
- **双向视角展示**：同时展示攻击方视角和受击方视角
- **响应式设计**：完美适配桌面端和移动端
- **直观交互**：点击属性卡片即可查看详细克制关系

### 适用场景

- 玩家对战前快速了解属性克制关系
- 宠物配队时分析属性组合策略
- 新手玩家学习属性系统入门指南

## 已实现功能

### 查询方式

1. **单属性查询**：点击属性选择器选择单一属性
2. **双属性查询**：连续选择两种属性进行组合查询
3. **链式导航**：在关系面板中点击属性可直接切换查询目标
4. **清除重置**：点击清除按钮返回初始状态

### 展示形式

- **攻击方视角**：展示该属性克制哪些属性（2倍伤害）和被哪些属性抵抗（0.5倍伤害）
- **受击方视角**：展示该属性被哪些属性克制和抵抗哪些属性
- **双属性特殊标识**：
  - 强力克制（3倍伤害）
  - 被克制（2倍伤害）
  - 我抵抗（0.5倍伤害）
  - 强力抵抗（0.25倍伤害）
- **伤害倍率标识**：清晰标注伤害倍率

### 算法说明

双属性克制关系采用标准游戏算法：

1. 分别计算攻击属性对两个防守属性的克制系数
2. 将两个克制系数相乘得到最终伤害倍率
3. 根据最终倍率进行分类展示

例如：火系+光系组合受草系攻击时

- 草系对火系：0.5倍（抵抗）
- 草系对光系：2倍（克制）
- 总倍率：0.5 × 2 = 1倍（正常伤害）

## 使用指南

### 环境要求

- Node.js &gt;= 18.0.0
- npm &gt;= 9.0.0

### 安装运行

```bash
# 克隆项目
git clone https://github.com/limitlm/RocomTypeTool.git

# 进入项目目录
cd RocomTypeTool

# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 预览生产版本
npm run preview
```

### 操作步骤

1. **启动应用**：运行 `npm run dev` 启动开发服务器
2. **选择查询模式**：在单属性、双属性或多属性查询间切换
3. **选择属性**：点击属性选择器中的属性卡片
4. **查看关系**：在面板查看属性的攻击和防御关系
5. **切换查询**：点击关系面板中的属性卡片可快速切换查询目标

## 技术架构

### 技术栈

- **前端框架**：Vue 3.4+ (Composition API)
- **构建工具**：Vite 5.2+
- **样式方案**：CSS3 (Scoped Styles)
- **图标方案**：Emoji Unicode

### 架构设计

```plaintext
src/
├── features/           # 功能模块目录
│   ├── common/          # 通用组件
│   │   ├── TypeSelector.vue      # 属性选择器组件
│   │   ├── RelationPanel.vue     # 单属性关系面板
│   │   └── DualRelationPanel.vue # 双属性关系面板
│   ├── single-query/  # 单属性查询模块
│   ├── dual-query/    # 双属性查询模块

│   └── featureConfig.js
├── data/              # 数据模块
│   └── types.js         # 属性数据和查询函数
├── App.vue            # 主应用组件
├── main.js            # 应用入口
└── style.css          # 全局样式
```
