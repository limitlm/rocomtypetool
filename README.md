
# 洛克王国属性克制查询工具（自用）

## 项目概述

市面上已经有很多属性克制查询小工具，本项目主要是为了方便个人使用而开发的。
我喜欢研究配队，想知道哪些属性组合成的配队，打击面和联防面能够同时覆盖较多的属性。
不过微信小程序上的配队都需要选择宠物，选择技能后才能查看，而且不能查看打击盲点和联防盲点，非常不方便，所以我索性自己写一个，可以免费部署到EdgeOnePages上。

### 核心功能

- **属性克制查询**：支持18种基础属性的克制关系查询
- **双向视角展示**：同时展示攻击方视角和受击方视角
- **响应式设计**：完美适配桌面端和移动端
- **直观交互**：点击属性卡片即可查看详细克制关系

### 适用场景

- 玩家对战前快速了解属性克制关系
- 宠物配队时分析属性组合策略
- 新手玩家学习属性系统入门指南

## 已实现功能

### 查询方式

1. **点击选择**：点击左侧属性卡片选择要查询的属性
2. **链式导航**：在关系面板中点击属性可直接切换查询目标
3. **关闭重置**：点击面板右上角关闭按钮返回初始状态

### 展示形式

- **攻击方视角**：展示该属性克制哪些属性（2倍伤害）和被哪些属性抵抗（0.5倍伤害）
- **受击方视角**：展示该属性被哪些属性克制和抵抗哪些属性
- **伤害倍率标识**：清晰标注2x（克制）和0.5x（抵抗）伤害倍率

### 数据来源

属性克制数据基于洛克王国手游官方属性克制表，确保数据的准确性和权威性。

## 使用指南

### 环境要求

- Node.js >= 18.0.0
- npm >= 9.0.0

### 安装运行

```bash
# 克隆项目
git clone https://github.com/limitlm/RocomTypeTool.git

# 进入项目目录
cd RocomTypeTool

# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 预览生产版本
npm run preview
```

### 操作步骤

1. **启动应用**：运行 `npm run dev` 启动开发服务器
2. **选择属性**：点击左侧属性网格中的任意属性卡片
3. **查看关系**：在右侧面板查看该属性的攻击和防御关系
4. **切换查询**：点击关系面板中的属性卡片可快速切换查询目标
5. **返回初始**：点击面板右上角关闭按钮返回选择界面
